# Code of Conduct

Be respectful, constructive, and considerate in repository issues, pull requests, reviews, and discussions.

This project welcomes clear technical feedback and contributors with different experience levels and backgrounds. Harassment, discrimination, threats, publishing private information, deliberate disruption, and repeated hostile behavior are not accepted.

Do not publish customer conversations, email content, provider credentials, mailbox credentials, or tenant data while discussing issues.

Report conduct concerns privately through the maintainer's GitHub profile. Maintainers may edit or remove content, close discussions, restrict participation, or block contributors when necessary to protect the project community.
